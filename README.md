# Theodia Guided Prayers

A dedicated repository of downloadable guided prayer sessions for the Theodia app.

| File | Tradition | Contents |
|---|---|---|
| `general-simple-guided-prayer.prayer.zip` | General | A gentle, ecumenical prayer session: pause, confess, give thanks, listen, intercede, and close with the Lord's Prayer. |
| `peace-and-rest.prayer.zip` | General | A guided session to release anxiety, receive God's peace, and rest in stillness before sleep or a stressful moment. |
| `catholic-guided-prayer.prayer.zip` | Catholic | Sign of the Cross, Our Father, Hail Mary, Glory Be, brief examen, and intercession. |
| `protestant-guided-prayer.prayer.zip` | Protestant | Scripture-centered session with confession, thanksgiving, listening, intercession, the Lord's Prayer, and a doxology. |
| `orthodox-guided-prayer.prayer.zip` | Orthodox | Trisagion, Jesus Prayer, stillness before icons in the heart, intercession, and blessing. |
| `jewish-guided-prayer.prayer.zip` | Jewish | Shema, blessings, reflection on the day, and personal supplication. |

## Format

Guided prayer packages use the `guided` package type. Each `.prayer.zip` contains a single JSON file with a guided session payload: prompts, durations, and optional TTS/audio settings.

## Source

These sessions are authored by Theodia for ecumenical and interfaith use across Christian and Jewish prayer traditions.
